# Statistiques Cyclo'Nord 2025

Analyse statistique des 613 commandes enregistrées par Cyclo'Nord en 2025.
Le classeur contient des indicateurs de position, de dispersion et une analyse par magasin.
Les calculs portent notamment sur le montant TTC, le prix unitaire, les notes clients, les quartiles et les valeurs atypiques.
Le montant typique d’une commande Cyclo'Nord est de **177 € de médiane** sur l’ensemble des 613 commandes enregistrées en 2025.
